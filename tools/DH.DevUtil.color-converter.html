HEX stores red, green, blue, and optional alpha as hexadecimal pairs. RGB describes channel intensity from 0 to 255. HSL separates hue, saturation, and lightness, while HSV uses value instead of lightness.

OKLCH is a perceptual color space: lightness, chroma, and hue are designed to track visual differences more consistently than RGB.

  • Contrast ratio is calculated from relative luminance, not from channel averages.
  • Use OKLCH for design adjustments, but check the final sRGB color for clipping and accessibility.
  • All processing happens in this browser tab.

HEX는 빨강·초록·파랑과 선택적인 alpha를 16진수로 표현합니다. RGB는 각 채널을 0~255로 표현하고, HSL은 색상·채도·명도를, HSV는 명도 대신 value를 사용합니다.

OKLCH는 지각 기반 색상 공간(perceptual color space)으로, RGB보다 사람이 느끼는 색 차이를 더 일정하게 다루도록 설계되었습니다.

  • 대비율(contrast ratio)은 채널 평균이 아니라 상대 휘도(relative luminance)로 계산합니다.
  • 디자인 색상 조정에는 OKLCH를 사용할 수 있지만, 최종 sRGB 색상의 clipping과 접근성도 확인해야 합니다.
  • 모든 처리는 현재 브라우저 탭에서 이루어집니다.
