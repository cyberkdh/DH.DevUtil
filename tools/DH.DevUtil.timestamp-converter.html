Unix timestamp: Unix time counts from 1970-01-01T00:00:00Z. Seconds are common in APIs; JavaScript Date uses milliseconds.

FILETIME and .NET Ticks: Windows FILETIME counts 100-nanosecond intervals from 1601-01-01. .NET Ticks use the same 100-nanosecond unit but start at 0001-01-01.

Time zones: ISO values ending in Z are UTC. A date-time without an offset is interpreted as local time by the browser. The result shows both UTC and local representations.
