CIDR writes an IPv4 network as an address followed by the number of network bits, such as 192.168.10.0/24. A larger prefix means a smaller network.

  • Network address is the first address in the block; broadcast is the last.
  • Traditional usable hosts exclude network and broadcast addresses. /31 and /32 use special host rules.
  • All processing happens locally in this standalone HTML file.
