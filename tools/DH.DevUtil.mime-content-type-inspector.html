A MIME type has a top-level type and subtype, optionally followed by parameters such as charset or boundary.
  • The Content-Type header describes the representation format, not necessarily the file on disk.
  • Structured syntax suffixes such as +json and +xml describe a structured representation.
  • A filename extension is only a hint; the header and actual content should be validated separately.
