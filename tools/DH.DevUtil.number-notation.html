What is E notation?

aEb (or aeb) means a × 10b. 1.5E3 is 1,500, 6.02e23 is 602,000,000,000,000,000,000,000, and 2.5e-4 is 0.00025. Programs, spreadsheets, and logs switch to this scientific notation when a number is very large or very small.

Engineering notation keeps the exponent a multiple of 3, so it maps directly onto SI prefixes: 250E-6 is 250 µ (micro), 4.7E+3 is 4.7 k (kilo).

Why does a stored value change?

A double (IEEE 754 binary64) keeps a 53-bit significand, about 15–17 significant decimal digits. A float (binary32) keeps 24 bits, about 6–9 digits. Most decimal fractions have no exact binary form, so 0.1 is stored as 0.1000000000000000055511151231257827…. This tool reads your text as exact decimal digits, then shows the value that would really be stored, rounded to nearest with ties to even.

Large integer IDs

JavaScript Number, JSON.parse, and many JSON libraries use double. Integers above 253 − 1 = 9,007,199,254,740,991 can silently change, for example 9007199254740993 becomes 9007199254740992. Send such IDs as strings, or use 64-bit integers or BigInt.

Excel and 1.23457E+15

Excel's General format displays long numbers in E notation with about 6 significant digits, and Excel stores only 15 significant digits. Digits after the 15th become 0, so a 16-digit card or account number cannot be recovered from the cell. Format the column as Text before typing or importing, or import the data as text.

Hex floats (C99, C++17, Java) use p for a power of two: 0x1.8p3 = 1.5 × 23 = 12. They describe a binary value exactly.

Korean units

Korean groups digits by four: 만 104, 억 108, 조 1012, 경 1016, 해 1020, 자 1024, 양 1028, 구 1032, 간 1036, 정 1040, 재 1044, 극 1048. For example 1,500,000,000,000,000 is 1,500조.

E 표기법(E notation)이란?

aEb(또는 aeb)는 a × 10b를 뜻합니다. 1.5E3은 1,500, 6.02e23은 602,000,000,000,000,000,000,000, 2.5e-4는 0.00025입니다. 프로그램, 스프레드시트, 로그는 숫자가 아주 크거나 작으면 이 과학적 표기법(scientific notation)으로 바꿔 보여 줍니다.

공학 표기법(Engineering notation)은 지수를 3의 배수로 맞추므로 SI 접두어와 바로 연결됩니다. 250E-6은 250 µ(마이크로), 4.7E+3은 4.7 k(킬로)입니다.

저장하면 값이 왜 바뀌나요?

double(IEEE 754 binary64)은 53-bit 가수(significand), 즉 유효숫자 약 15~17자리를 보관합니다. float(binary32)는 24-bit, 약 6~9자리입니다. 대부분의 10진 소수는 2진수로 정확히 표현되지 않아서 0.1은 0.1000000000000000055511151231257827…로 저장됩니다. 이 도구는 입력을 정확한 10진 숫자로 읽은 뒤, 실제로 저장될 값을 최근접 짝수 반올림(round to nearest, ties to even) 규칙으로 보여 줍니다.

큰 정수 ID

JavaScript의 Number, JSON.parse, 많은 JSON 라이브러리는 double을 씁니다. 253 − 1 = 9,007,199,254,740,991보다 큰 정수는 조용히 바뀔 수 있습니다. 예를 들어 9007199254740993은 9007199254740992가 됩니다. 이런 ID는 문자열로 주고받거나 64-bit 정수, BigInt를 사용하세요.

Excel과 1.23457E+15

Excel의 일반(General) 서식은 긴 숫자를 유효숫자 약 6자리의 E 표기로 보여 주고, 값 자체도 유효숫자 15자리까지만 보관합니다. 16번째 자리부터는 0이 되므로, 16자리 카드번호나 계좌번호는 셀에서 원래 값을 복구할 수 없습니다. 입력하거나 가져오기 전에 열 서식을 텍스트(Text)로 지정하거나, 데이터를 텍스트로 가져오세요.
