YAML is often used for human-readable configuration. JSON is stricter and is commonly used for APIs and machine-readable interchange.
  • Mappings become JSON objects; sequences beginning with `-` become JSON arrays.
  • Indentation defines nesting in the supported YAML subset, so use spaces consistently.
  • This standalone tool supports common configuration-style YAML, not every YAML 1.2 feature.
