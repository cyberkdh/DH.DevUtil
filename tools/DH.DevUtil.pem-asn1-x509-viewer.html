PEM is a text container around Base64 DER bytes. ASN.1 defines the data structure, and X.509 defines the certificate profile.

  • A certificate signature proves that the issuer signed the certificate; it does not make the certificate trusted by itself.
  • Issuer, Subject, Validity, Subject Alternative Name, and Key Usage are common fields to inspect.
  • This viewer parses structure locally and is not a complete certificate path validator.

No value is uploaded. This is a standalone HTML tool.
