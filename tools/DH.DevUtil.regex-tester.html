What is a regex? A regular expression is a small language for describing text. Literal characters match themselves; character classes such as \d match a category; quantifiers such as + control repetition; parentheses create groups.
Read from left to right: ^ and $ anchor the text, [...] chooses one character, (...) groups a pattern, ? makes something optional, and | means “or”. Start with a small pattern and test it against examples.
Flavor matters: this page uses the browser's JavaScript RegExp engine. Python, .NET, Java, PCRE2, Rust, and other engines share many basics but differ in named-group syntax, lookbehind support, Unicode properties, replacement syntax, and flags. Always check the target language before copying a pattern.
Safety: Regular expressions can be slow when nested quantifiers cause catastrophic backtracking. Keep patterns specific, avoid ambiguous constructs such as (a+)+, and never use an unreviewed regex for untrusted large input in a critical service.
