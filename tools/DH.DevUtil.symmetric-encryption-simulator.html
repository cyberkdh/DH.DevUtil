Other algorithms and legacy ciphers

ARIA is a modern standardized block cipher with 128-, 192-, and 256-bit keys. It is not included in the browser Web Crypto API, so it is not offered here. Symmetric Encryption Simulator (Base) implements ARIA for learning.

DES has an inadequate 56-bit effective key. 3DES/TDEA is a legacy cipher with a 64-bit block size and is not appropriate for new encryption. They are intentionally not offered as operational choices; use them only to understand legacy compatibility, not to protect data.

ECB is also omitted because it reveals repeated plaintext patterns. This simulator focuses on AES-GCM, AES-CBC, and AES-CTR.

AES-GCM/CTR use Web Crypto; AES-CBC uses a built-in JavaScript AES implementation. Keys and messages are not uploaded or stored. Do not reuse a GCM nonce or CTR counter with the same key. CBC and CTR do not authenticate ciphertext.
