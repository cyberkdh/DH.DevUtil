Password hashing is different from a fast general-purpose hash. A password KDF intentionally costs time so large numbers of guesses become more expensive.

  • Salt prevents identical passwords from producing the same stored value.
  • Iterations increase the work required for every guess.
  • PBKDF2 is available through the browser Web Crypto API. Production systems should follow current platform guidance and use an appropriate password KDF.
