JWT Inspector

Emulate a local issuer, parse compact JWTs, and verify HS256 signatures. Parsing reveals data; it does not establish trust.

Learning tool only. Use synthetic tokens and temporary keys only. JWTs can contain sensitive claims. All processing stays in this browser; no network requests or persistent storage are used.
