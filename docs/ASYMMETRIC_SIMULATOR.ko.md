# Asymmetric Cryptography Simulator

[English](./ASYMMETRIC_SIMULATOR.md)

브라우저 Web Crypto API로 공개키·개인키 연산을 학습합니다.

## 기능

- RSA-OAEP 암호화·복호화.
- ECDSA 서명·검증.
- ECDH shared secret 파생.
- 브라우저가 지원하는 경우 Ed25519 서명·검증.
- 메모리에서 생성된 public JWK와 연산 설명.

[Asymmetric Cryptography Simulator](../tools/DH.DevUtil.asymmetric.html)를 엽니다. key는 메모리에서만 생성되며 업로드하거나 저장하지 않습니다.
