# UUID / ULID Inspector

[English](./UUID_ULID_INSPECTOR.md)

UUID와 ULID 식별자를 로컬에서 생성하고 검사합니다.

## 기능

- UUID v4, UUID v7, ULID 생성.
- version, variant, timestamp, 형식 검사.
- 네트워크 요청 없이 복사 가능한 결과 제공.

[UUID / ULID Inspector](../tools/DH.DevUtil.uuid-ulid.html)를 열고 식별자를 생성하거나 검사창에 붙여 넣으세요.

UUID v7과 ULID에는 생성 시간이 포함되므로 해당 metadata를 숨겨야 하는 경우 주의해야 합니다.
