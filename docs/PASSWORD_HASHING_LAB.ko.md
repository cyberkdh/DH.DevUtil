# Password Hashing Lab

[English](./PASSWORD_HASHING_LAB.md)

Password Hashing Lab는 비밀번호 파생값의 원리를 학습하는 브라우저 로컬 도구입니다. PBKDF2와 SHA-256·SHA-384·SHA-512, 반복 횟수, salt, 키 길이, 비밀번호 검증을 확인할 수 있습니다.

## 기능

- 브라우저 Web Crypto API로 무작위 salt 생성
- SHA-256·SHA-384·SHA-512를 사용하는 PBKDF2 파생
- 반복 횟수와 파생 키 길이를 바꾸며 매개변수 확인
- 현재 파생 패키지에 대해 다른 비밀번호 검증
- Password와 검증 입력란의 비밀번호 표시를 각각 전환
- 알고리즘, 반복 횟수, 키 길이, salt, 파생값을 포함한 저장 형식 JSON 복사
- English·한국어 UI 전환

## 중요 보안 안내

- 학습용 도구입니다. 운영 비밀번호, 인증 정보, 실제 비밀값을 입력하지 마세요.
- 비밀번호 파생값은 암호화(encryption)가 아니며 원래 비밀번호를 복호화할 수 없습니다.
- Salt는 일반적으로 파생값과 함께 저장합니다. 비밀번호 비밀값은 아니지만 고유해야 합니다.
- 브라우저 Web Crypto API에서 사용할 수 있는 PBKDF2를 보여줍니다. 운영 시스템에서는 현재 플랫폼 지침을 따르고 환경에 맞는 password KDF를 선택해야 합니다.
- 기본 매개변수가 모든 운영 시스템에 적합하다고 보장하지 않습니다.

## 개인정보 보호

모든 파생과 검증은 현재 브라우저 탭에서 이루어집니다. 값을 외부로 전송하거나 저장하지 않습니다.
