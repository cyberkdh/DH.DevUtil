# URL / Query Parser

[한국어](./URL_QUERY_PARSER.ko.md)

Parse URL components and edit query parameters without sending the URL anywhere.

## Features

- Protocol, username, host, port, pathname, hash, and origin inspection.
- Add, update, and remove query parameters.
- Repeated parameters and percent-encoding are handled by `URLSearchParams`.
- Copy the rebuilt URL.

Open [URL / Query Parser](../tools/DH.DevUtil.url-query.html) and paste a URL. Relative URLs require a base URL when used outside the browser address bar.
