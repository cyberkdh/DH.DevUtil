# Text · JSON Diff

[English](./TEXT_JSON_DIFF.md)

Text · JSON Diff는 두 값을 브라우저에서 비교하고 추가·삭제·동일 줄을 표시합니다. JSON 모드에서는 양쪽을 파싱하고 형식화한 뒤 비교합니다.

## 기능

- 일반 텍스트를 줄 단위로 비교
- 양쪽을 JSON으로 파싱하고 형식화한 뒤 비교
- 원본·변경본 줄 번호와 색상별 추가·삭제 표시
- 예제 불러오기, 양쪽 형식화, 지우기, Diff 복사
- 기본 텍스트, API JSON, 설정 JSON, Markdown, 로그 샘플 제공
- `file1`·`file2` editor에 로컬 파일을 직접 끌어 놓아 양쪽 입력에 불러오기
- Unified, 좌우 비교(Side-by-side), Inline, 단어, 문자, 이동 줄, 요약, JSON Path, JSON Tree, Patch, 변경 히트맵 보기 전환
- 공백·대소문자·빈 줄·주석·JSON 속성 순서·끝 쉼표 무시, 변경 부분만 표시, 변경 주변 문맥 줄 수 선택
- English·한국어 UI와 학습 가이드 전환
- 독립 실행형 HTML에서 모든 값을 로컬 처리

## 사용 방법

1. [Text · JSON Diff](../tools/DH.DevUtil.text-json-diff.html)를 엽니다.
2. 소스 코드, 로그, Markdown, 일반 텍스트는 **Text** 모드를 선택합니다.
3. 구조화된 데이터는 **JSON** 모드를 선택합니다. 잘못된 JSON은 비교 전에 오류로 표시됩니다.
4. 결과 패널에서 초록색 추가 줄과 빨간색 삭제 줄을 확인합니다.
5. 로컬 파일을 비교할 때 각 editor에 파일을 직접 끌어 놓습니다. 파일 내용은 브라우저에서만 읽습니다.

## 중요 사항

- 현재 구현은 longest common subsequence(LCS) 알고리즘으로 줄을 비교합니다.
- JSON 형식화는 두 칸 들여쓰기를 사용합니다. 속성 순서가 다르면 변경으로 표시될 수 있습니다.
- 비교 전에 UTF-8 BOM과 CRLF/LF/CR 줄바꿈 차이를 정규화하므로 운영체제의 줄바꿈 방식만 다른 동일한 줄은 변경으로 표시하지 않습니다.
- 매우 큰 입력은 메모리 내 비교 표를 만들기 때문에 브라우저 메모리를 더 사용할 수 있습니다.
- 단어·문자 강조는 변경된 줄 쌍의 공통 접두·접미를 기준으로 한 간결한 비교입니다. 이동 줄 감지는 동일한 줄 내용을 기준으로 하는 휴리스틱(heuristic)입니다.

## 개인정보 보호

결과 보기는 브라우저 창 높이에 맞춘 내부 스크롤 영역을 사용합니다. 페이지 scrollbar는 화면에서 숨기지만 마우스 휠·터치·키보드로 페이지 이동은 계속할 수 있습니다. 현재 보기는 로컬 `.txt` 파일로 저장할 수 있으며, Patch 보기는 `.patch` 확장자를 사용합니다.
`Comparison input` 패널은 접어서 결과에 집중할 수 있습니다.

모든 처리는 현재 브라우저 탭에서 이루어집니다. server endpoint, 외부 library, upload 기능, 입력값 영구 저장 기능이 없습니다. 선택한 UI 언어는 `localStorage`에 저장될 수 있습니다.
