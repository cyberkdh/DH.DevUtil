# UUID / ULID Inspector

[한국어](./UUID_ULID_INSPECTOR.ko.md)

Generate and inspect UUID and ULID identifiers locally.

## Features

- UUID v4, UUID v7, and ULID generation.
- Version, variant, timestamp, and format inspection.
- Copy-ready output with no network request.

Open [UUID / ULID Inspector](../tools/DH.DevUtil.uuid-ulid.html), generate an identifier, or paste one into the inspector.

UUID v7 and ULID timestamps expose creation time; they are not suitable when that metadata must remain hidden.
