# Cron Explainer

[한국어](./CRON_EXPLAINER.ko.md)

Explain common five-field Unix cron expressions and calculate upcoming local times.

## Features

- Minute, hour, day-of-month, month, and day-of-week fields.
- Wildcards, lists, ranges, and step values.
- Human-readable field descriptions and the next eight matching times.
- Runs entirely in the browser.

Open [Cron Explainer](../tools/DH.DevUtil.cron.html). It intentionally focuses on common Unix cron syntax; extensions such as `L`, `W`, `#`, seconds, and Quartz syntax are not interpreted.
