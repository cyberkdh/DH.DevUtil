# CIDR Calculator

[English](./CIDR_CALCULATOR.md)

CIDR Calculator는 독립 실행형 HTML에서 IPv4 네트워크 정보를 로컬로 계산합니다.

## 기능

- `/0`부터 `/32`까지 IPv4 주소와 CIDR 프리픽스 처리
- 네트워크, 브로드캐스트, 서브넷 마스크, 와일드카드 마스크, 전체 주소 수, 사용 가능 호스트 수, 호스트 범위 표시
- 주소와 마스크의 이진수 표시
- `/25`부터 `/30`까지 더 긴 프리픽스로 서브넷 분할
- 서버 전송 없는 입력값 검증
- English·한국어 UI 전환

## 사용 방법

1. [CIDR Calculator](../tools/DH.DevUtil.cidr-calculator.html)를 엽니다.
2. `192.168.10.37/24` 같은 주소를 입력합니다.
3. 정규화된 네트워크 블록과 호스트 범위를 확인합니다.
4. 더 긴 프리픽스를 선택하면 분할된 서브넷 목록을 확인할 수 있습니다.

## 중요 사항

- 현재 IPv4만 지원합니다.
- 일반적인 사용 가능 호스트 수는 네트워크·브로드캐스트 주소를 제외합니다. `/31`은 point-to-point 링크를 위해 두 주소를 반환하고 `/32`는 한 주소를 반환합니다.
- 브라우저 응답성을 위해 서브넷 표는 최대 4,096행으로 제한합니다.

## 개인정보 보호

모든 처리는 현재 브라우저 탭에서 이루어집니다. 값을 외부로 전송하거나 저장하지 않습니다.
