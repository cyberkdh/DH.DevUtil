# Number Notation Converter

[English](./NUMBER_NOTATION_CONVERTER.md)

Number Notation Converter는 `1.23457E+15`, `2.5e-4`처럼 E 표기법(E notation)으로 적힌 값을 읽기 쉬운 숫자로 바꿔 주는 도구입니다. 입력을 정확한 10진 숫자로 읽기 때문에 자릿수가 길어도 정밀도가 손실되지 않습니다. IEEE 754 `double`이나 `float`에 실제로 저장될 값도 함께 보여 줍니다.

## 화면 미리보기

![Number Notation Converter 화면 미리보기](./images/DH.DevUtil.number-notation.png)

왼쪽에 값을 입력하면 오른쪽에 값마다 한 줄씩 접힌 결과가 나옵니다. 줄을 펼치면 모든 표기와 복사 버튼, double·float32 저장값, 안내 문구를 볼 수 있습니다.

## 기능

- 여러 값을 한 번에 변환합니다. 줄바꿈, 탭, 세미콜론, 또는 쉼표 뒤 공백으로 값을 구분합니다.
- 다음 입력 형식을 받습니다.
  - E 표기: `1.5E3`, `1.5e+3`, `-2.5e-4`, `.5e2`
  - 10의 거듭제곱: `1.5 × 10^3`, `1.5*10**3`, `10³`
  - 자릿수 구분자(digit separator): `1,000,000`, `1 000 000`, `1_000_000`, `1'000'000`(C++14)
  - 언어 접미사(suffix) `f`, `d`, `m`
  - `0x`, `0b`, `0o` 정수와 `0x1.8p3`, `0x1.8p3f` 같은 16진 실수(hex float)
- 각 값을 다음 형식으로 보여 주며, 행마다 복사 버튼이 있습니다.
  - 일반 표기(모든 자릿수)
  - 천 단위 구분: 구분자를 쉼표, 공백, 밑줄, 아포스트로피 중에서 선택
  - 과학적 표기(`1.5E+3`, `1.5 × 10³`)
  - 지수를 3의 배수로 맞춘 공학 표기(Engineering notation)
  - SI 접두어(`250 µ`, `4.7 k`)
  - 한국어 단위(만, 억, 조, 경 … 극)
- 유효숫자, 정수부 자릿수, 소수 자릿수를 셉니다.
- `double`(binary64)과 `float32`(binary32)에 실제로 저장되는 정확한 값, 같은 값으로 되돌아가는 가장 짧은 문자열, 반올림 차이와 overflow/underflow를 보여 줍니다.
- 정수가 2<sup>53</sup> − 1을 넘으면 경고합니다. 이 값은 JavaScript `Number`와 많은 JSON 파서가 정확히 보관할 수 있는 가장 큰 정수입니다.
- 값이 Excel이 긴 숫자를 표시한 형태로 보이면 안내합니다. Excel이 저장하지 않은 자릿수는 복구할 수 없기 때문입니다.
- Learn more 섹션에서 E 표기법, 부동소수점 저장, 큰 정수 ID, Excel 동작, 언어별 리터럴(literal), 한국어 단위를 설명합니다. 설명은 English와 한국어로 전환할 수 있습니다.
- 모든 처리는 외부 라이브러리, 네트워크 요청, 영구 저장 없이 브라우저 안에서 이루어집니다. 브라우저가 기억하는 설정은 Learn more 언어 선택뿐입니다.

## 사용 방법

1. 최신 브라우저에서 [Number Notation Converter](../tools/DH.DevUtil.number-notation.html)를 엽니다. HTML 파일 하나만으로 동작합니다.
2. **Values**에 값을 입력하거나 붙여 넣습니다. **Load examples**를 눌러 예제를 불러올 수도 있습니다. 입력하는 대로 결과가 바뀝니다. 결과는 값마다 한 줄로 접혀 있고 입력값 → 천 단위 구분 값(오류면 오류 메시지)을 보여 줍니다. 줄을 누르면 펼쳐지며, **Expand all** / **Collapse all**로 한꺼번에 펼치거나 접을 수 있습니다.
3. **Digit grouping**에서 **Grouped** 행에 쓸 구분자를 고릅니다. C++14 리터럴에는 아포스트로피를, C#, Java, JavaScript, Python 리터럴에는 밑줄을 쓰세요.
4. 행마다 **Copy**를 누르거나, **Copy all plain values**를 눌러 모든 일반 표기 결과를 한 줄에 하나씩 복사합니다.

## 변환 방식

- 입력 문자열을 부호, 10진 숫자열, 10의 지수로 나눠 읽습니다. 모든 10진 표기는 소수점 위치만 옮겨서 만들기 때문에 17자리가 넘는 값도 정확합니다.
- 일반 표기는 최대 1,200자까지 보여 줍니다. `1e5000`처럼 더 긴 값은 과학적 표기로만 보여 줍니다.
- IEEE 754 결과는 정수 연산으로 직접 계산하며, 최근접 짝수 반올림(round to nearest, ties to even) 규칙을 따릅니다. 무작위 값 20,000개로 브라우저의 `Number()`, `Math.fround()` 결과와 일치하는지 확인했습니다.
- 저장값(stored value)은 2진 값을 10진수로 정확히 펼친 값입니다. 예를 들어 double의 `0.1`은 `0.1000000000000000055511151231257827021181583404541015625`입니다.
- 최단 문자열(shortest text)은 같은 저장값으로 되돌아가는 가장 짧은 10진 문자열입니다. double의 경우 JavaScript `String()` 출력과 같습니다.

## 참고 및 제한

- 지수 범위는 10진 입력이 ±1,000,000,000, 16진 실수가 ±100,000입니다.
- `Infinity`와 `NaN`은 유한한 숫자가 아니므로 거부합니다.
- 쉼표와 공백은 정수부의 세 자리 묶음(`1,234,567`)일 때만 천 단위 구분자로 받아들입니다. 일부 지역에서 쓰는 소수점 쉼표(decimal comma)는 지원하지 않으므로 `1,5`나 `1.234,56`은 오류로 처리합니다.
- 숫자 묶음 사이의 공백은 자릿수 구분으로 읽으므로 `100 200`은 값 하나(100200)가 되고, 결과에 이 사실을 안내합니다. 서로 다른 값은 줄을 나눠 입력하세요.
- 아포스트로피(C++14)와 밑줄(C#, Java, JavaScript, Python)은 정수부와 소수부의 두 숫자 사이 어디에나 쓸 수 있지만, 소수점 바로 옆이나 지수에는 쓸 수 없습니다.
- `m` 접미사(C# `decimal`)는 받아들이지만 C# decimal 연산은 시뮬레이션하지 않습니다.
- Excel 안내는 표시 형태를 보고 판단한 힌트일 뿐이며, 값이 실제로 어디서 왔는지는 알 수 없습니다.
