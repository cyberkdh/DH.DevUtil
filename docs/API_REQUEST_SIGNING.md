# API Request Signing Simulator

[한국어](./API_REQUEST_SIGNING.ko.md)

Build a generic canonical request and sign it locally with HMAC-SHA-256.

## Features

- Method, path, query, headers, and body inputs.
- SHA-256 payload digest.
- Deterministic canonical request preview.
- Base64 and hexadecimal signature output.

This is a generic teaching model, not a vendor-specific authentication protocol. Open [API Request Signing Simulator](../tools/DH.DevUtil.api-signing.html) and never use production secrets in a learning page.
