# JSON Parser 안내

[JSON Parser](../tools/DH.DevUtil.json.html)는 별도 설치 없이 브라우저에서 실행되는 단일 HTML 도구입니다.

[English](./JSON_PARSER.md)

## 기본 사용법

1. HTML 파일을 브라우저에서 엽니다.
2. **Source** 입력창에 JSON 텍스트를 붙여 넣습니다.
3. `Parse`를 선택해 JSON 문법을 검증하고 결과를 표시합니다.
4. 입력을 수정한 뒤에는 `Parse`를 다시 실행해 결과를 갱신합니다.

빈 입력이나 잘못된 JSON은 상태 영역에 오류로 표시됩니다. 유효한 JSON이면 root type, 값/멤버 수, depth, 입력 크기를 보여줍니다.

## 결과 탐색 및 변환

- **Tree**: 객체와 배열을 계층 구조로 표시합니다. 노드를 개별적으로 펼치거나 접고, `Expand all` 및 `Collapse all`로 트리 전체를 제어합니다.
- **JSON**: 파싱된 값을 JSON 텍스트로 표시합니다.
- **Format**: 2칸 또는 4칸 들여쓰기를 선택해 JSON을 형식화합니다.
- **Minify**: 불필요한 공백과 줄바꿈을 제거합니다.
- **Copy result**: 현재 변환 결과를 클립보드에 복사합니다.
- 입력과 원문 값의 word wrap을 켜거나 끌 수 있습니다. 긴 scalar 값은 트리에서 일부만 표시될 수 있으며, 전체 값은 `View as` → `Raw value`에서 확인하고 복사할 수 있습니다.

## Base64 및 이미지 미리보기

값이 Base64로 인식되면 `View as` 메뉴에서 다음 표현을 확인하고 복사할 수 있습니다.

- Base64
- Hex
- C# `byte[]` initializer
- C++ `unsigned char` array

인식 가능한 Base64 이미지 데이터는 `Preview image`로 브라우저에서 미리 볼 수 있습니다. 미리보기에서 이미지 크기와 MIME type을 확인하고 다운로드할 수 있습니다. 임의의 외부 URL을 가져오는 기능은 아닙니다.

## 처리 및 개인정보

입력 JSON은 브라우저 탭 안에서 파싱됩니다. 도구는 입력 내용을 서버로 전송하지 않으며 외부 스크립트 라이브러리를 사용하지 않습니다. 민감한 JSON을 다룰 때는 신뢰하는 브라우저와 로컬 HTML 사본을 사용하고, 브라우저 확장이나 호스트 페이지가 입력을 수집하지 않는 환경인지 확인하세요.

## 제한 사항

- 문법 검증은 브라우저의 표준 `JSON.parse` 동작을 따릅니다. JavaScript 객체 리터럴, 주석, 후행 쉼표는 유효한 JSON이 아니므로 허용되지 않습니다.
- 파일 업로드나 JSON 파일 import UI는 제공하지 않습니다. JSON 텍스트를 입력창에 붙여 넣어 사용하세요.
- 이미지 미리보기는 Base64 값에서 인식 가능한 이미지 데이터로 제한됩니다.
